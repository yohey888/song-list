# 歌リストサイト

Excel（`songs.xlsx`）を読み込んで、歌った曲の一覧をブラウザで表示するサイトです。
**Excelを差し替えるだけで更新できます。** プログラムを触る必要はありません。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体（デザイン・機能すべてこの1ファイル） |
| `songs.xlsx` | 曲のデータ。「全楽曲」シートを読み込みます |
| `README.md` | この説明書 |

## サイトの機能

- 曲名・アーティスト・関連作品のキーワード検索（ひらがなとカタカナ、大文字と小文字、スペースの違いは区別しません）
- ジャンルでの絞り込み（アニソン／ボカロ／ドラマ／ジブリ／その他）
- 並び替え（Excelの順番／曲名／アーティスト）
- アーティスト名を押すと、そのアーティストの曲だけを表示
- 「コピー」ボタンで「曲名 / アーティスト」をコピー（リクエストするときに便利です）
- 「🎲 おまかせ」で、表示中の曲からランダムに1曲を選ぶ
- 曲数・アーティスト数・更新日（Excelの「〇〇まで更新」セル）を自動で表示
- スマホ表示とダークモードに対応

## ① 最初の公開手順（制作者向け・1回だけ）

1. GitHubにログインし、右上の「＋」→「New repository」を押します。
   - Repository name：例 `song-list`
   - **Public** を選ぶ（無料で公開するために必要です）
   - 「Create repository」を押す
2. 作ったリポジトリの画面で「uploading an existing file」を押し、`index.html`・`songs.xlsx`・`README.md` をドラッグ&ドロップします。そのあと「Commit changes」を押します。
3. 「Settings」→ 左メニューの「Pages」を開きます。
   - Source：**Deploy from a branch**
   - Branch：**main**、フォルダは **/(root)** を選んで「Save」を押す
4. 1〜2分待つと、同じ画面に公開URL（`https://ユーザー名.github.io/song-list/`）が表示されます。

### お客様を招待する

「Settings」→「Collaborators」→「Add people」で、お客様のGitHubユーザー名を入力します。
お客様が招待メールを承認すると、Excelを更新できるようになります。

### タイトルを変える

`index.html` の上の方にある `CONFIG` の部分だけを書き換えます。

```js
title: "〇〇の歌リスト",
description: "これまでに歌った曲の一覧です。",
```

GitHubの画面で `index.html` を開き、鉛筆アイコン（Edit）から直接編集できます。

## ② 曲を追加・更新する手順（お客様向け）

1. いつもどおりExcelを編集します（「全楽曲」シートの **曲名／アーティスト名／関連作品** の列）。
2. ファイル名を **`songs.xlsx`** にして保存します。
3. GitHubのリポジトリを開き、「Add file」→「Upload files」から `songs.xlsx` をドラッグ&ドロップします。
4. 「Commit changes」を押します。
5. 1〜2分でサイトに反映されます（表示が変わらないときはページを再読み込みしてください）。

> 更新日は、Excelの「2026/10/18まで更新」のセルがそのまま表示されます。ここも忘れずに書き換えてください。

### 公開前に確認したいとき

パソコンで `index.html` をダブルクリックし、「Excelファイルを選んで表示」から新しいExcelを選ぶと、アップロードする前に見た目を確認できます。

## 安全性・プライバシー

- サイトは閲覧者の情報を集めません（フォーム、Cookie、アクセス解析、広告なし）。
- 外部のスクリプトやライブラリは読み込んでいません。セキュリティ設定（CSP）で、外部への通信と外部スクリプトの実行を止めています。
- Excelに悪意のある文字列が入っていても、サイト上ではただの文字として表示されます。
- ページ下部の「このサイトについて」に、プライバシー・著作権・ご利用にあたっての説明を載せています。運営者名や連絡先は `CONFIG` の `owner` と `contact` に入れると表示されます。

## 注意点

- **公開リポジトリなので、Excelファイルも誰でもダウンロードできます。** 見られて困るメモなどは、Excelに書かないでください。
- 「全楽曲」シートの名前と、1行目の見出し（曲名／アーティスト名／関連作品）は変えないでください。
- 漢字の曲名は「読み」ではなく文字コード順に並ぶため、五十音順とは少しずれます。
- ジャンルボタンは「関連作品」に含まれる言葉で自動で分けています。ジャンルを増やしたいときは、`index.html` の `genres` に1行追加します。
